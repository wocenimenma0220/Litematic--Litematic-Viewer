# 投影预览 1.0.8

离线查看 Minecraft Litematica 投影（`.litematic`），支持实时 3D 预览和 PNG / GIF 导出。

## 启动

完整解压 ZIP 到一个文件夹，双击根目录的 **投影预览.exe**。
也可以把 `.litematic` 文件拖到 EXE 上打开。请保留 EXE 旁的 assets、bin、runtime、webapp 文件夹。

适用于 Windows 10/11 64 位。包内已包含 Java 和 Electron，无需额外安装 Java 或 Node。
启动器使用 Windows 自带的 .NET Framework。导出结果保存在 renders，启动日志在 logs。

命令行导出：

```
投影预览.exe --cli "投影文件的完整路径.litematic" "输出图片的完整路径.png" 1024 1024 45 30
```

最后四个参数为宽、高、旋转角、俯仰角，均可省略。中文路径建议使用完整路径。

## 背景、全屏与首次启动

默认使用网格背景。预览区右上角可切换天空色、白色、深灰或自选背景色，也可导入不超过 10 MB 的 PNG / JPG 背景。图片按比例铺满并居中裁切，保存在 settings 中，重新启动后仍可使用。PNG 和 GIF 导出使用选定的背景；勾选“透明背景”则导出透明图像。

点击“全屏”或按 F11 切换全屏，按 Esc 退出。全屏期间仍可操作侧栏及预览。

左侧操作面板的右边缘中央有收起按钮；收起后点击左边缘的展开按钮即可恢复。收起状态会在重新启动后保留，预览自动扩大，已打开的投影、缩放和镜头角度不变。

启动时会显示作者 kinda sus 的欢迎弹窗。“网页链接”在默认浏览器打开指定网页；“关闭”只关闭本次弹窗，“后续不再显示”会保存选择，之后启动不再弹出。图标采用用户提供的 icon.jpg，内置到 EXE 和窗口中。

## 头颅与告示牌

玩家头颅支持真实皮肤，包含基础头部和帽子外层，保留地面 16 个旋转方向及墙面四个朝向。兼容新版 profile 和旧版 SkullOwner：优先使用投影保存的皮肤纹理地址；只有玩家名或 UUID 时，通过 Minecraft 官方公开接口查询。无需登录账号。

首次缺少皮肤时默认联网获取，之后优先使用 skins/textures 和 skins/profiles 中的本地缓存。侧栏“玩家头颅”可关闭联网，关闭后仍能使用缓存；没有资料、下载失败或超时时继续显示 Steve。下载并行且有等待上限，不会无限等待网络。缓存保留首次获取的皮肤，玩家换肤后可删除对应缓存重新获取。

也可以输入头颅对应的玩家名或 UUID，导入 64×64 或旧版 64×32 的皮肤 PNG。导入文件保存为 skins/local 中的本地覆盖，优先于在线皮肤。骷髅、僵尸等其他头颅目前仍使用 Steve 占位模型。

告示牌默认使用内置 Minecraft 字体：英文来自原版 bitmap，中文来自官方资源索引中的 Unifont。字体文件位于 assets/builtin/minecraft-font，随便携 ZIP 一起解压，无需安装系统字体或联网下载。支持中英文、数字和常见标点，其他文字脚本不显示。

普通文字使用原版染色后的暗色并跟随环境光照；使用荧光墨囊的文字保持全亮，带原版描边。正反面分别读取颜色与荧光标记，保留四行中的空行，按普通/悬挂告示牌的宽度裁切过长文字。3D 预览、PNG 和 GIF 使用同一组文字像素。

## 特殊模型与漫游查看

参考 Enhanced Block Entities 1.21.4，补全普通箱子、陷阱箱、末影箱及双箱的静态模型，支持潜影盒全部 17 种颜色和六个朝向、钟的四种悬挂方式，以及装饰陶罐随朝向旋转的四面纹样。陶罐纹样从投影保存的数据读取，兼容新旧格式；没有纹样的面使用砖面。床继续使用当前原版资源的方块模型。EBE 模型的来源说明和 LGPL 许可证随包放在 assets/builtin/static-block-entities 中。

按 V 进入漫游模式，移动鼠标即可转视角，无需按住左右键。画面中央使用内置原版 Minecraft 十字准星，左键查看准星所指方块的名称、投影坐标和状态。点选依据模型实际表面，贴图的透明空洞不会挡住后方方块。进入漫游时会尝试锁定鼠标以持续转向；若系统不允许，仍能在预览区移动鼠标转向。按 Esc 释放鼠标并暂停视角，点击预览区继续，按 V 退出漫游。轨道预览仍支持拖动旋转。

打开查看面板会自动释放鼠标，方便查看详情或操作左栏。关闭面板按钮或点击预览区可继续漫游；Esc 关闭面板并保持视角暂停。准星与面板只用于预览，不会进入 PNG / GIF 导出。

容器面板将同种物品且 NBT 相同的多组内容合并显示数量，并记录来源槽位，点击物品可展开详细数据。比较时只忽略物品根层的数量和容器槽位，保留附魔、自定义名称、耐久度、嵌套内容及 NBT 数字类型的差别；字段排列不同不影响合并。支持新旧物品格式和双箱两侧合并，也能查看陶罐、讲台、唱片机等保存的物品。该功能只读，不会修改投影。投影未保存容器数据、尚未生成战利品、缺少另一半箱子或末影箱个人库存时会显示相应提示，避免误报为空容器。

漫游的鼠标输入现在合并到每帧一次绘制，空闲时不重复绘制。大量透明面的排序改为复用内存的 64 位深度基数排序，保持与原先的深度排序结果一致；视角未转动时继续复用透明面顺序。鼠标控制采用 [Pointer Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_Lock_API)。

## 指定实体

现在读取投影中保存的普通实体，显示全部七类矿车、各木材的船和运输船（包括竹筏）、雪傀儡、铁傀儡及成年/幼年猪灵。兼容旧版通用 boat/chest_boat 的 Type 木材字段和新版各木材实体 ID。其他种类暂不显示，隐形实体沿用保存的隐形状态；预览统计会显示实际渲染的实体数量。

模型保留保存的位置、水平朝向和头部俯仰。支持雪傀儡的南瓜头开关、铁傀儡的生命值裂纹、矿车载物与自定义 DisplayState、常见成年猪灵盔甲及手持物品，乘客使用载具座位位置并避免重复显示。船舱深度遮挡会阻止水面显示在船内部，完全浸没时保留水面；竹筏保持开放结构。负尺寸区域的方块和实体使用各自正确的坐标起点。

漫游准星也可点选这些实体，查看实体状态和保存的数据。运输矿车、漏斗矿车、运输船的内容物显示继续按相同物品及相同 NBT 合并。实体同时出现在实时预览、PNG 和 GIF 中；采用静态姿态，不运行生物 AI、物理或行走动画。复杂装备外观、幼年盔甲及盔甲纹饰尚未完整支持。

## 已完成的渲染修复

- 透明几何按当前视角逐面排序，玻璃、水和传送门使用共同的前后顺序。
- 修正轨道视角排序方向，移除固定坐标分桶引起的视角错误。
- 含水树叶使用正确的水流体身份，修正水面高度及相邻水面衔接。
- 水与树叶、透明方块交界处使用水覆盖贴图。
- 修正水面反面重复混合和半透明材质中不透明像素错误写入深度的问题。
- 内缩面及未指定剔除方向的模型从自身所在位置读取光照，保留环境光下限。
- 预览透明背景使用与混合输出一致的预乘透明度，避免额外压暗。
- 删除旧诊断入口、测试投影、试验启动器代码及未使用的旧函数。

透明度采用面中心排序并预先细分较大的面；复杂相交的透明几何仍可能存在局部排序误差。

## 从源码构建

需要 JDK 21 或更新版本、Windows 自带 C# 编译器，以及已安装的 Electron 依赖。默认会用完整 JDK 的 jlink 构建运行时；已有 runtime 时可使用 -ReuseRuntime。编译产物以 Java 21 为最低运行版本。
首次安装 Electron 可运行 install.bat。

```powershell
powershell -ExecutionPolicy Bypass -File verify.ps1
powershell -ExecutionPolicy Bypass -File package.ps1
```

package.ps1 会重新编译引擎、构建启动器和便携运行时，并生成：

- dist/投影预览/：便携运行目录。
- dist/投影预览-1.0.8.zip：可分发压缩包，EXE 直接位于 ZIP 根目录。
- 投影预览.exe：源码目录的启动器。

应用源代码在 src 和 webapp，启动器源码在 tools/launcher。
针对透明排序、含水树叶、告示牌、皮肤缓存、特殊模型和漫游查看的回归检查位于 tools/verify，不会进入分发包。便携运行时包含 HTTPS 所需的加密模块。

## 已知限制

复杂文字组件的加粗、斜体及翻译键未完整支持；指定清单以外的实体和旗帜图案等尚未支持。
静态模型、材质包和流体渲染来自内置资源；不同材质包可能影响透明分类与视觉表现。
