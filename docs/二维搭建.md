# 二维搭建

从顶部菜单“二维搭建”选择侧视或俯视进入，点击“返回”回到原有投影界面。首次进入为空画布，两种视角在本次运行中分别保留自己的画布；不会自动把上次运行的暂存内容放到初始画布上。

- 左键放置，按住拖动可连续绘制；选择橡皮擦后左键擦除。
- 空白位置右键拖动画布；方块上右键拖动方块，保留全部状态。目标位置已被占用时取消移动，中键也可拖动画布。
- 滚轮以鼠标位置为中心缩放，范围 25%–400%；“归位”恢复初始视图。
- 上拉工具栏顶部的横条，展开到界面高度的 61.8%；下拉收起。也可以点击横条切换，展开后方块列表使用剩余空间滚动。
- 底部按原版创造模式的建筑、染色、自然、功能、红石、管理员方块分类，另有水、岩浆、地狱门分类；可按中文名或方块 ID 搜索。
- 按方块的实际属性展示状态，包括铁轨全部斜坡与转弯、楼梯内外角和半部、台阶单双层、门铰链与开合、按钮附着面、中继器延迟和锁定、比较器模式、红石粉连接和信号强度等。方向和形状直接显示贴图缩略图，完整属性值在悬停提示中查看。双层台阶不能含水。侦测器沿用只显示方向的约定。
- 方块激活状态由用户选择，不执行红石电路模拟。没有光照计算。
- 工具栏、状态选项和画布均使用平面正投影；薄方块优先选择投影面积最大的那一面，铁轨展示完整轨面，不展示成一根侧边线。铜箱子保留箱体、箱盖、锁扣及不同氧化阶段的实体贴图。
- 成功放置方块时播放对应的原版音效，保留原版随机样本、音量和音高；重复放置相同状态不会重复触发。冰、浮冰、蓝冰分别使用 `render/1.MP3`、`render/2.MP3`、`render/3.MP3`，以原速播放。
- 地狱门采用普通石质方块的放置音效。
- 水流每 150 毫秒更新一次。侧视优先下落，遇到支撑后横向传播最多七格；俯视按水平切片处理，向四个方向扩散，最多七步。移除水源后退水，含水方块持续供水。水冲掉可冲毁的红石元件，接触静态岩浆源方块时生成黑曜石。岩浆本身不模拟流动。
- 画布每轴范围为 ±192 格；水流是二维近似，并非原版三维世界的完整流体引擎。
- 每次拖动形成一步撤销，最多保留 60 步；支持 Ctrl+Z、Ctrl+Shift+Z。
- 自动暂存在本机；“保存”（Ctrl+S）导出 JSON，“打开”恢复视角、方块及全部状态。兼容早期版本的画布文件。

目录和像素贴图由 `tools/generate-board-catalog.py` 根据工作区附带的原版资源、创造模式分类、StateDefinition 及现有静态方块实体模型生成。默认优先使用 XK redstone display 的模型、方块状态和材质；缺失资源回退到内置模型和原版资源。分别生成侧视、俯视和物品图标的平面投影，自动避开薄模型的侧边，保留元素旋转与 multipart 条件。特殊实体模型没有平面贴图时显示占位图标。

`tools/generate-board-sounds.py` 从本机 MC 资源索引和声音文件读取放置音效，并按原版 `Blocks`、`SoundType`、`SoundEvents` 和 `BlockItem` 配置生成音效表。仅把实际使用的样本复制到应用内，运行时不依赖 MC 文件夹。原版明确为静音的方块保留静音行为。

验证：`node tools/verify/board-regression.cjs`、`node tools/verify/board-audio-regression.cjs`；界面验证：`node tools/verify/board-ui.cjs`（需 Playwright 和 Microsoft Edge），包含实际音频文件解码检查。
